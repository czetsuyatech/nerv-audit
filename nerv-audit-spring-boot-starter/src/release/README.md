# NERV Audit Spring Boot Starter

This starter assembles NERV Audit dependencies and contains no implementation
classes. Its sources and Javadoc JARs therefore contain this notice.

Implementation sources and API documentation are available in the corresponding
sources and Javadoc artifacts for `nerv-audit-core`, `nerv-audit-operations`, and
`nerv-audit-operations-web` at the same version as this starter.

Project documentation and source code: https://github.com/czetsuyatech/nerv-audit
